== Description ==

Zapline is a free block theme by Pretty Things Online. A loud, high-contrast theme with electric lime on black, oversized uppercase type and hard-edged buttons.

It includes three colour styles (Zapline, Daylight, Ultraviolet), locally bundled fonts, and ready-made patterns for a hero, features, image and text, testimonials, a newsletter call to action, a latest posts grid, a full home page and an about page. Templates cover the blog, single posts, pages, archives, search results and 404, plus "Page without title" and "Landing page" templates.

Great for creators, bands, streetwear labels, gaming, tech launches and agencies.

== Installation ==

1. In your admin panel, go to Appearance > Themes and click Add New Theme.
2. Click Upload Theme, choose the theme zip file and click Install Now.
3. Click Activate.
4. Go to Appearance > Editor to change colours, fonts, templates and patterns.

== Frequently Asked Questions ==

= How do I change the colours? =

Open Appearance > Editor > Styles and pick one of the included style variations, or set your own colours.

= How do I build a home page like the demo? =

Create a page, choose the "Landing page" template and insert the "Zapline: Home page" pattern. Then set it as your homepage under Settings > Reading.

= Can I remove the footer credit? =

Yes. Edit the Footer template part in Appearance > Editor > Patterns. Keeping it is a kind way to say thanks.
