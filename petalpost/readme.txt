== Description ==

Petalpost is a free block theme by Pretty Things Online. A soft, editorial theme with rose and cream tones, a classic serif and gently rounded cards.

It includes three colour styles (Petalpost, Sage, Midnight), locally bundled fonts, and ready-made patterns for a hero, features, image and text, testimonials, a newsletter call to action, a latest posts grid, a full home page and an about page. Templates cover the blog, single posts, pages, archives, search results and 404, plus "Page without title" and "Landing page" templates.

Great for makers, florists, candle and ceramics studios, lifestyle bloggers and small boutiques.

== Installation ==

1. In your admin panel, go to Appearance > Themes and click Add New Theme.
2. Click Upload Theme, choose the theme zip file and click Install Now.
3. Click Activate.
4. Go to Appearance > Editor to change colours, fonts, templates and patterns.

== Frequently Asked Questions ==

= How do I change the colours? =

Open Appearance > Editor > Styles and pick one of the included style variations, or set your own colours.

= How do I build a home page like the demo? =

Create a page, choose the "Landing page" template and insert the "Petalpost: Home page" pattern. Then set it as your homepage under Settings > Reading.

= Can I remove the footer credit? =

Yes. Edit the Footer template part in Appearance > Editor > Patterns. Keeping it is a kind way to say thanks.
